# Storage top screen

A React Native (Expo) implementation of the supplied storage-header design.

## Run

Install dependencies with your preferred package manager, then start Expo:

```bash
npm install
npm start
```

Use `npm run android`, `npm run ios`, or `npm run web` to open a specific target.
