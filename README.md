# Travel screen

React JS app using Vite and npm.

## Development

```sh
npm install
npm run dev
```

Open `/travel-screen-2`. The root URL opens this screen automatically.

## Validation

```sh
npm run build
```

Use `npm run preview` to preview the production build. No test framework is configured.

The supplied design contains no navigation or animation metadata. View Location opens a map search. Image nodes contain no assets, so their dimensions are preserved with unfilled placeholders. Roboto, Montserrat, Inter and Lato load through Google Fonts and require network access.
